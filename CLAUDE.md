# Instruções para o Claude neste projeto

Este projeto gera infográficos SVG de genograma para o livro "Infops livro 4 - Genealogia" (família Pires).

**Antes de gerar, editar ou discutir qualquer infográfico neste projeto, leia primeiro [IDENTIDADE_VISUAL.md](IDENTIDADE_VISUAL.md).** Esse arquivo contém todas as convenções de layout, tipografia, formatação de nome/cônjuge, regras de fotos, tabelas de espaçamento e o padrão de divisão em séries de várias partes — já validadas em várias sessões anteriores com o usuário. Siga essas regras por padrão; não redescubra ou reinvente convenções que já estão documentadas ali.

Pasta de fotos: `D:\IABRACADABRA\0058 - Família Pires\Fotos do Livro` (e a pasta antiga `Novas Fotos`, checar as duas). Sempre confirme o nome exato do arquivo de foto na pasta antes de usar — nomes/extensões digitados pelo usuário frequentemente não batem exatamente com o arquivo real.

Ao terminar cada infográfico, se surgir uma convenção nova ou uma correção de regra, atualize o `IDENTIDADE_VISUAL.md` para manter o guia vivo.
